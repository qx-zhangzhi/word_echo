IELTS Reading · True / False / Not Given

判断题信号词与避坑

判断题不是判断常识，也不是看题干和原文有没有同一个词。核心是比较：对象、范围、程度、方向、关系。
TRUE 原文明确说了同一件事，只是换了说法。
FALSE 原文明确说反了：对象、范围、程度、时间、因果、比较方向有冲突。
NG 原文没有回答题干那件事；尤其是题干多加了比较、原因、目的、唯一性。
最稳动作
划题干核心词，定位原文后只对 5 件事：对象同不同，范围大不大，程度准不准，方向反不反，关系有没有。
段落匹配技巧目的、方法、发现、优缺点 Not Given 专区最容易误判的地方
题干信号 → 原文确认 → 假信号
做题时不要急着选。先定位，再判断题干有没有“偷偷加戏”。
True 的感觉 原文和题干说的是同一个对象、同一个范围、同一个方向。词可以完全不同。
False 的感觉 原文有明确相反证据。不是“没找到”，而是“找到了反着说”。
Not Given 的感觉 题干问了一个关系或细节，原文只说了相关背景，没有给答案。
绝对词
all / every / always / never / only / must / completely
怎么判断
题干有绝对词，原文必须也支持这个绝对范围。原文如果只是 somemanyoftencanmay，通常不能 True。
避坑：绝对词不一定必错，但必须有强证据。one of the most 不等于 the most；almost all 不等于 all。
程度词
most / many / some / few / mainly / partly / rarely
怎么判断
精确对程度：some 不等于 most，many 不等于 all，mainly 不等于 partly。
避坑：题干把程度放大，经常是 False；原文根本没说比例，常是 Not Given。
比较关系
more than / less than / better than / compared with
怎么判断
比较题要看三点：比较对象、比较指标、比较方向。A 比 B 快，不能变成 B 比 A 快。
避坑：原文只说 A 很快，题干说 A 比 B 快，通常 Not Given，因为比较关系没给。
最高级唯一
first / only / best / largest / most important / unique
怎么判断
题干出现“首次、唯一、最大、最重要”，原文必须明确给这个极值或唯一性。
避坑：原文说 a major reason，题干写 the main reason，程度变强；原文说 one of the first，题干写 the first，范围变窄。
时间顺序
before / after / since / until / previously / now / in 1990
怎么判断
对齐时间点和先后顺序。原文是 after，题干变 before，就是明确反向。
避坑：since 有时是“自从”，有时是“因为”。时间题优先找年份、年代、世纪、before/after 的对象。
因果关系
because / due to / lead to / result in / caused by
怎么判断
原文必须也表达 A 导致 B。只说 A 和 B 同时出现，不等于 A 导致 B。
避坑：题干常偷偷加 because。原文没给原因，只是相关或并列，优先 Not Given，不要凭常识选 True。
目的关系
aim / purpose / in order to / designed to / intended to
怎么判断
题干说“为了……”，原文要有目的信号：to doin order todesigned tointended toaimed at。
避坑：原文说做了 X，题干说做 X 是为了 Y。若目的 Y 没出现，多半 Not Given。
对象偷换
children / adults / researchers / participants / government
怎么判断
主语必须一致或能被原文包含。children 不能随便换成 adults；researchers 不能随便换成 participants。
避坑：对象不同不一定都是 False。原文没提题干对象，是 Not Given；原文明确排除题干对象，才是 False。
范围偷换
all countries / some areas / urban / rural / worldwide
怎么判断
看地点、人群、时间、条件有没有被扩大或缩小。原文 some countries，题干 all countries，通常不成立。
避坑：原文小范围，题干大范围，多数是 False 或 Not Given；判断关键是原文有没有明确否定大范围。
否定表达
not / no / never / fail to / lack / without / little
怎么判断
遇到否定词，先判断方向。原文有，题干无；原文无，题干有，都可能变成反向。
避坑：little 有时是“几乎没有”，a little 是“有一点”。fail to do 是“未能做成”，不要漏掉。
观点事实
believe / argue / claim / according to / evidence shows
怎么判断
原文是某人观点，题干说成客观事实，要小心。题干如果写 X believed，原文也要对应 X 的观点。
避坑：Some experts believe A 不等于 A is true。观点来源、说话人、态度方向都要对齐。
可能性
may / might / can / could / likely / certain / impossible
怎么判断
区分“可能、能够、很可能、一定”。原文 may，题干改成 will/certain，程度变强。
避坑：can 表示“有能力/可能”，不是一定发生。likely 也不是 certain。
数量数字
number / percent / twice / half / majority / minority
怎么判断
数字题不只看数字，还要看单位、对象、时间、比例基准。50% of adults 不等于 50% of children。
避坑：more than 50% 和 about 50% 不同；increase by 20% 和 increase to 20% 不同。
条件限制
if / unless / only if / provided that / except / limited to
怎么判断
条件词决定一句话什么时候成立。题干省掉条件，可能把一句有限成立的话变成普遍成立。
避坑：原文 under certain conditions，题干直接说 always works，范围被放大，通常 False。
定义改写
means / refers to / is known as / called / defined as
怎么判断
定义题看核心属性是否一致。题干可能把定义里的必要条件删掉，或把例子说成定义。
避坑：such as 后面是例子，不是定义。A includes B 不等于 A means B。
变化趋势
increase / decline / become / no longer / used to / now
怎么判断
看变化方向和时间起点。原文说增加，题干说减少，是 False；原文说现在，题干说过去，要核时间。
避坑：原文只描述现在状态，题干说“已经变得……”，如果没有过去对比，可能 Not Given。
例子归纳
for example / such as / including / one case
怎么判断
例子只能证明它所在句子的观点，不能自动推广到所有情况。
避坑：原文说 A is an example of B，题干说 all B are A，范围倒置，通常不成立。
让步转折
although / however / nevertheless / yet / instead / rather than
怎么判断
转折后常是作者重点，但判断题可能考转折前的让步内容。题干问哪一半，就读哪一半。
避坑：看到 however 不要自动选反。先确认题干说的是被反驳的旧观点，还是转折后的新观点。
Not Given 专门判断
missing comparison / missing reason / missing purpose / missing number
怎么判断
题干和原文主题相关，但题干多问了一个原文没回答的东西：谁更多、为什么、为了什么、是否唯一、是否所有。
避坑：相关不等于 True；没找到反话也不等于 False。原文没有回答，就是 Not Given。

信号词扫读法

题干里的抽象词不是拿来翻译的，是拿来判断信息类型的。先把它归类，再去原文扫对应结构，最后读前后一句确认。
1题干划词：aim, method, finding, drawback, comparison...
2判断类型：目的、方法、发现、优缺点、原因、结果、对比...
3扫原文信号：to do, by, found that, lead to, however...
4读前后一句：确认是同义匹配，不是碰巧撞词。
一句话原则
信号词是定位雷达，不是答案机器。扫到以后必须做“前后一句确认”：能不能回答题干问的那个信息功能。
最稳 目的找 to do，方法找 by/using，研究找 found that。
最危险 to, by, as, found, however 都可能是假信号。
最后确认 太宽、太细、方向反、只是例子，都不要选。

适合段落匹配、信息匹配、人物观点匹配。Heading 题也能用，但 Heading 最后要回到整段主旨。
目的
aim / purpose / goal / objective / intention
扫这些
to doin order toso as todesigned tointended toaimed atfor the purpose of
避坑：不是所有 to do 都是目的。能自然翻成“为了……”，才算目的；people began to leave 只是动作。
方法
method / approach / technique / way / means / strategy
扫这些
byusingviathroughwithbased onrely onmake use of
避坑：by 可能接年份、作者、地点。by 1990 是时间，written by Smith 是作者；后面接动作、工具、手段才是方法。
研究发现
finding / discovery / found / conclusion
扫这些
found thatshowed thatrevealed thatsuggested thatdiscovered thataccording toresearch indicates
避坑：found 也可能是“找到某物”。主语是 study, research, researchers, survey, experiment 时，才更像研究发现。
优点
advantage / benefit / positive / strength / merit
扫这些
beneficialadvantageoususefulvaluableeffectiveefficientimprovesave timereduce cost
避坑：原文常不写 advantage，而写具体好处。更快、更便宜、更准、更安全、更方便，都可能是 benefit。
缺点限制
disadvantage / drawback / limitation / weakness / negative
扫这些
limitedlimitationweaknessshortcomingdrawbackexpensivedifficultunreliabletoo...tolack
避坑：limited to adults 只是研究范围，不一定是缺点。要看它有没有导致不能推广、效果差、成本高、无法使用。
原因
reason / cause / why / factor / explanation
扫这些
becausesinceasdue toowing tocaused byresult fromreason forexplain
避坑：as 很滑，可能是“当……时 / 作为…… / 因为……”。只有能换成 because 的 as 才算原因。
结果影响
effect / impact / consequence / result / outcome
扫这些
lead toresult incauseproducethereforethusconsequentlyas a resultaffect
避坑：result 可能是“研究结果”，不一定是因果结果。能画成 A → B，才是 consequence 或 impact。
例子案例
example / case / illustration / instance
扫这些
for examplefor instancesuch aslikeincludinga caseone exampleillustrated by
避坑：段落匹配问“提到例子”可以直接用；Heading 题不要选例子本身，要找例子证明的观点。
定义概念
definition / meaning / concept / term / known as
扫这些
refers tomeansis defined asis known ascalleddescribesis a kind of
避坑：is / are 太常见。确认它是不是在解释“这个词是什么意思”，而不是普通描述。
变化发展
change / shift / development / evolution / transition
扫这些
changeshiftbecomedevelopevolveno longerused tooncepreviouslynowincreasingly
避坑：develop 也可能是“开发产品”。找过去 vs 现在、旧情况 vs 新情况，才是变化类。
对比差异
comparison / contrast / difference / unlike / similarity
扫这些
whilewhereasunlikecompared within contrastby contrastdifferent fromsimilar tohowever
避坑：however 只是转折，不一定是对比。确认是否真的有两个对象 A 和 B。
解决建议
solution / measure / recommendation / response
扫这些
solveaddresstackledeal withovercomepreventreduceshouldneed torecommendpropose
避坑：should 可能只是空泛态度。后面有具体动作，才是 solution 或 measure。
未来预测
future / prediction / prospect / expectation / likely
扫这些
willwouldmaymightcouldlikelyexpected topredicted toin the futurenext decade
避坑：may / could 也可能只是“不确定”。有未来时间或 expected / predicted，才更稳。
争议不确定
debate / controversy / disagreement / uncertainty / doubt
扫这些
debatecontroversialdisagreedisputeunclearuncertainunknownquestiondoubtnot clear
避坑：question 可能只是普通“问题”。要看是不是观点冲突、结论未定、证据不足。
分类类型
type / category / class / group / classification / kind
扫这些
typekindcategorygroupclasscan be divided intofall intoconsist of
避坑：多个例子不等于分类。分类必须有“分成几类”的结构。
过程步骤
process / stage / step / phase / procedure / sequence
扫这些
firstthennextfinallystagestepphaseprocessfollowed by
避坑：first 可能只是“第一次”。有连续动作链，才是 process。
重要性作用
importance / significance / role / function / contribution
扫这些
importantsignificantcrucialessentialkeyplay a rolecontribute tohelpenableallow
避坑：important 只是评价词。确认它“对什么起作用”，以及作用结果是什么。
数量趋势
increase / decrease / trend / growth / decline / rise / fall
扫这些
increaserisegrowexpandmoredecreasedeclinefalldropreducefewerless
避坑：单个数字不是趋势。至少要有变化方向：上升、下降、变多、变少。
时间顺序
when / period / era / before / after / sequence
扫这些
beforeafterduringuntilsincefrom...toin the 19th centuryearlylaterpreviously
避坑：before / after 后面可能是逻辑顺序，不一定是时间。题干问 period 时，优先找年份、世纪、年代、阶段名。
人物观点
claim / argue / believe / opinion / view / attitude
扫这些
argueclaimbelievethinksuggestpoint outaccording toin X's viewX says
避坑：according to 后面可能是资料来源，不一定是观点。确认是否有“某人认为/主张”的内容。
态度评价
attitude / criticism / support / concern / praise
扫这些
supportcriticisepraiseworryconcerndoubtwelcomeopposepositivenegativeskeptical
避坑：态度题看方向，不看单词情绪。concern 可能是“涉及”，也可能是“担忧”；要读前后句。
极值唯一
first / only / most / least / best / worst
扫这些
firstonlyuniquethe mostthe leastlargestsmallestbestworstneveralways
避坑：first 可能是步骤，也可能是历史首次。题干问“首次/唯一/最大”时，要确认比较范围。
让步反驳
although / however / nevertheless / instead / rather than
扫这些
althoughthoughwhilehoweverneverthelessyetinsteadrather thannot...but
避坑：转折前后都可能被出题。Heading 通常看转折后主观点；细节匹配要看题干问的是被否定内容还是作者主张。
范围条件
condition / exception / range / only if / unless
扫这些
ifonly ifunlessprovided thatunder certain conditionsexceptwithinlimited todepend on
避坑：条件和限制很容易漏。看到题干有 only, except, specific, under conditions，一定读完整句。
